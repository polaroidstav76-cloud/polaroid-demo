# Демо-версия сайта фотоцентра

Отдельная копия сайта для показа. Подключена к своей базе Supabase (`mautbgsvpafzirkawbrh`) с выдуманными данными:
клиенты, продажи, смены и отчёты придуманы, рабочая база сюда не подключена.

- `index.html`, `formula.js` — сайт (копия основного сайта).
- `config.js` — адрес демо-базы и полоса «Демо-версия».
- `spravochnik/` — картинки справочника.
- `seed/` — генератор выдуманных данных.
- `supabase/functions/staff-admin` — функция управления учётками сотрудников.
